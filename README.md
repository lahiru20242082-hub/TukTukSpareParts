\# TukTukSpareParts -  Tuk-Tuk Depot Inventory System



A simple JavaFX inventory management system for a local tuk-tuk spare parts business.

Made for CM1601 Programming Fundamentals Coursework.



\## Requirements

\- JDK 21

\- JavaFX 21

\- IntelliJ IDEA



\## How to Run

1\. Open this project folder in IntelliJ IDEA

2\. Make sure JavaFX library is added

3\. Run Main.java from src folder

4\. The app window will open



\## Project Files

\- SparePart.java - Model class for spare parts with encapsulation

\- Dealer.java - Model class for dealers

\- Main.java - JavaFX main application



\## Data Files

\- inventory\_legacy.txt - Original dirty data file

\- inventory\_cleaned.txt - Cleaned data after removing bad rows

\- inventory.txt - Working file used by the app

\- dealers.txt - Dealers data



\## Features

\- Add new spare parts

\- View all parts

\- Search parts by name or category

\- Low stock alert

\- Dealer management

\## My Approach

I used simple comma replacement method for dirty data cleaning with manual trimming,

not using any advanced libraries. Threshold is set to 12 for all parts initially.
